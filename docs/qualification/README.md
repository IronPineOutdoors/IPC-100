# IPC-100 Qualification Evidence

This directory contains controlled analysis and qualification records used to turn IPC-100 requirements into exact selection and verification envelopes.

- [PPQ-01 Power Performance Qualification](PPQ-01_Power_Performance_Qualification.md)
- [PPQ-02 Remaining Power Performance Qualification](PPQ-02_Remaining_Power_Performance_Qualification.md)
- [PPQ-02 Power Component Evidence Register](Power_Component_Evidence_Register.md)

Qualification evidence does not itself select MPNs, assign footprints, or authorize PCB work.
