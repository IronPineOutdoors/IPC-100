# IPC-100 Engineering Specifications

This directory contains controlled, cross-subsystem engineering specifications that translate the frozen IPC-100 architecture and interface contracts into measurable design and verification limits.

- [QER-01 Quantitative Electrical Requirements](QER-01_Quantitative_Electrical_Requirements.md) — Rev A operating, power, load, transient, protection, passive, connector, signal, derating, thermal, and design-target envelope.

Specifications define requirements; they do not by themselves select parts, assign footprints, authorize PCB work, or prove compliance. Analysis and test evidence shall be traced to the applicable specification revision.
